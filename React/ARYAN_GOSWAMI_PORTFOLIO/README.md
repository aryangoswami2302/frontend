# Aryan Goswami Portfolio

A responsive, dark-only portfolio for Aryan Goswami, built with React, Vite, Tailwind CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run lint
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Vercel will use the included configuration: `npm ci` to install, `npm run build` to build, and `dist` as the output directory.
4. Select **Deploy**. Future pushes to the production branch will deploy automatically.

No environment variables are required.
